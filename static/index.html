ДАННЫЕ ДЛЯ ПОДБОРА

Загрузить каталог

Импорт заменяет товары только выбранного магазина. Каталоги других участников сохраняются.

Обязательные поля: id, name, description, category, type, price, in_stock. Для точного подбора добавьте атрибуты совместимости. Необязательное поле url открывает товар на сайте магазина; без него работает демо-карточка. В примере замените ссылки example.com своими.
